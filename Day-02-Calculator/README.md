# 🧮 Python Advanced Calculator

A command-line calculator built with Python as part of my **Python Projects — Day 2** learning series.

This project started as a basic calculator and was upgraded with multiple mathematical operations, calculation history, input validation, previous-result tracking, and a user-friendly menu system.

## 🚀 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* % Modulus
* 🔢 Power
* // Floor Division
* √ Square Root
* 📊 Percentage Calculation
* |x| Absolute Value
* 📜 Calculation History
* 🗑️ Clear Calculation History
* 🔄 Previous Result Tracking
* 📊 Total Operation Counter
* ❌ Input Validation
* 🚫 Division-by-zero protection
* 🔄 Continuous calculations without restarting the program

## ▶️ How to Run

Clone the repository:

```bash

```

Navigate to the project:

```bash
cd python-projects/Day-02-Calculator
```

Run the program:

```bash
python main.py
```
